Inventory Manager

Questo progetto consiste nello sviluppo di una semplice applicazione web
per la gestione di un inventario prodotti.

L'applicazione permette di visualizzare, aggiungere, modificare e cancellare
prodotti tramite un'interfaccia dinamica. I dati vengono salvati nel browser
utilizzando LocalStorage.

Funzionalità principali:
- login e logout amministratore
- visualizzazione lista prodotti
- aggiunta, modifica ed eliminazione prodotti (CRUD)
- salvataggio dati lato client

Tecnologie utilizzate:
- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
